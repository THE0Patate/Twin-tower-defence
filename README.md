# This is Twin tower defence.
Le but du jeu est d'empeicher que les évènements du 9/11 arrive pour de vrai. 
Avec un hélocoptère, vous avez la posibilité d'exploser des mesquins terroristes qui osent tenter de détruire le World Trade Center. 
Pour ce faire, utilisez les flèches HAUT et BAS pour vous contrôlez dans ces directions.
Vous pouvez aussi lancer des missiles avec la flèche GAUCHE.
Enfin, Vous pouvez lancer des missiles à partir du tank avec la flèche DROITE.
Détruire des mesquins donne 100 pts, détruire des gentils fait perdre 100 pts. Lorsqu'un gentil atteind la tour, cela donne 1000 pts. Dans le même cas, mais avec un mesquin, vous perdez 6900 pts.
Vous gagnez 10 pour chaque frame que vous défendez les tours.

Bon jeu.

PS. Pour l'application web et Pandas, utilisez le fichier Python original.
